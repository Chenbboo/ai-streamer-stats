# 老板查看员工考勤

## 使用方式

- 老板工作台增加“员工考勤”，进入现有 `/hcm/attendance`；人力资源的考勤入口继续可用。
- 有组织读取权限时，默认选择第一个授权公司，展示该公司全部员工的已同步日记录。可切换公司、搜索并选择员工、修改日期；清空员工选择恢复全部员工，切换公司清空员工选择。
- 普通员工默认查看本人；公司读取人员也可切换“仅看本人”。保留上下班打卡、排班、请假和已通过补卡展示。未同步仍提示无记录，不推断缺勤。
- 考勤状态支持全部、全部异常、迟到、早退、缺卡及未打卡。按飞书明确返回的 `Late`／`Early`／`Lack` 筛选异常；`Todo` 单独查询，不根据当天未完成打卡、未知或陈旧数据推断异常。一天内任一班段符合条件就保留该员工当天的完整明细。先收齐来源并合并日记录，再筛选和分页，切换状态返回第一页。
- 考勤页新增范围、员工筛选及日期提示提供中文和越南语；老板工作台沿用该页现有中文。

## 权限与升级

- 增量迁移 `V083__boss_employee_attendance.sql` 补齐 `company_owner` 的本人读取、组织读取和考勤菜单父级；不重新执行旧版 V067，也不授予飞书技术配置权限。
- `/business/feishu/query-options` 的员工目录与记录接口共用公司实际负责人／显式组织授权校验。只返回员工标识、显示姓名及部门，不返回登录名等额外信息。
- 角色权限不等于全公司范围。员工不能查询他人或公司全部记录；老板不能越过授权公司；技术管理员也需要业务公司范围。
- 复用现有公司人员目录（包含未同步人员，上限 2000）；列表无记录不表示该员工缺勤。调离公司或已删除账号的历史记录仍可在公司全部记录中查看，员工筛选目录沿用当前组织归属。
- 发布时需应用 V083、更新前后端并重新登录以刷新菜单权限。发布包、服务器备份和健康检查结果以实际发布记录为准。
