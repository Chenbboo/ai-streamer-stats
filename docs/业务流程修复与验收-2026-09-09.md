# 业务流程修复与验收 · 2026-09-09

根据业务流程复核方案完成代码、数据库升级及本地运行服务更新。保留工作区此前已有修改，以新增记录和明确的业务操作衔接原流程。

## 功能与入口

| 流程 | 本次处理 | 使用入口 |
| --- | --- | --- |
| 当日无花费 | 独立确认，不制造零元成本流水；随后可继续新增支出，展示以实际花费为准 | 负责人工作台 → 今日无支出 |
| 收支重复提交 | 新表单生成唯一提交编号，失败重试复用；主动新建另一笔使用新编号。已保存但响应丢失时返回原记录，复用编号且改变主要业务内容时拒绝 | 原有收入、花费及手动收支表单 |
| 负责人交接 | 保存新旧计费角色生效日期；原负责人可留任成员或退出。退出时通过已有任务、持续工作转交流程保存执行期间和事件记录；已计价成本保留 | 项目中心 → 更换主负责人 |
| 持续工作项目结项 | 允许仅有持续工作记录的项目进入结项检查；仍检查待处理工作、未完成任务和里程碑及高风险。结项说明、实际截止日期和交付／关账分离沿用已有规则 | 原有结项／验收入口 |
| 离职办理 | 检查负责项目与未完工作的交接，登记生效日期。生效时退出在执行项目、结束相关投入和工作期间，停用账号并撤销登录。保留已结项项目的成员历史 | 人员管理 → 人员详情 → 离职与交接 |
| 公司人员成本口径 | 在原项目归集之外，按同人同日去重展示；同人同日金额、公司或币种不一致时显示待核对，不猜测金额 | 收支经营 → 去重人员成本 |
| 暂停期间成本 | 显式选择保留人员或释放人员。释放从明天开始停止新增工作日成本，恢复当天重新计费；既有计价记录保留 | 项目中心 → 暂停项目 |
| 关账后纠错 | 独立调整单，可关联原流水或登记漏记业务；归属老板审核后按审核当日记录经营结果差额。技术管理员不能代替老板签认 | 已关账项目 → 交付与结算 → 关账后调整 |

离职计费截至生效日，包含当天；未来申请由后台每分钟检查。待生效和失败的申请可取消。交接条件在生效前变化时显示失败原因，处理后重新办理。重新入职须更新任职状态、重新启用账号并按需重新加入项目。

公司去重展示范围为当前用户有权查看的项目、当前筛选和核算日，仅处理成员工作日口径，不代表全公司工资实付。旧项目的自定义参与结束日期继续有效。缺少费率或日历的人员成本仍提示待完善，不自动填写金额。

关账后调整单的差额在收支经营单独展示并给出含调整经营结果；原项目日结果继续反映关账时的历史口径。当前按审核日期入账，没有新增独立的公司会计期间管理模块。
