# 越南语界面翻译与验收

## 修改范围

补齐项目经营、财务核算、人员与部门、珠宝进销存、直播管理、系统管理及公共组件的固定界面文案。包括菜单与标签页、表格、筛选项、表单、弹窗、校验、上传下载提示、状态和计量单位显示、常见后端错误信息。

Element Plus 的日期、分页、确认框等组件随中越语言切换；启动加载页、浏览器标题、缓存标签页和后端未配置越南语名称的已知菜单也使用当前语言。越南语表单标签与按钮允许换行。

用户录入的名称、分类、备注、正文与业务数值保留原文。翻译只作用于显示标签及已知系统消息，不重写 API 业务记录。商品规格 `精品/普通`、默认单位 `件` 等存储值保持兼容。自定义单位仍可输入。

后端生成的 Excel 表头、历史附件正文及 AI 动态生成内容不经过此界面翻译层。本次未修改统计 SQL、业务审批权限或后端计算逻辑。

## 维护方式

- 固定文案使用模板 `$tr('中文原文', [参数])` 或脚本 `translateText('中文原文', [参数])`。
- 译文集中在 `frontend/src/locales/vi-text.json`，保留原有 `zh-CN.js / vi-VN.js` 和组件内既有双语文案。
- 插值使用完整句子和 `{0}` 等占位符，避免按中文语序拼接越南语短语。
- `server-patterns.json` 只匹配已知完整消息模板，插入的项目名、人员名等数据不自动翻译。
- 新增固定文案后运行 `pnpm run check:i18n`，检查未翻译的中文、缺失译文、占位符及既有双语键的一致性。
- `.localization/` 保存临时检查日志与截图，已忽略。`src/views/tool/build/` 是表单构建器源码，已从通用 `build/` 忽略规则中排除，确保其翻译可以随源码保存。

## 验证

1. 全前端静态检查覆盖 258 个源码文件；检查八千余条译文及 138 个参数化后端消息模板。
2. 翻译专项测试验证中越切换、插值、业务名称保留及商品规格/单位提交值；现有工具函数测试继续执行。
3. 浏览器使用隔离的模拟 API，覆盖 35 个页面的中越两种语言、12 类新增弹窗、商品带数据展示和两种语言下的保存请求，共 96 项检查；另验证语言菜单切换及刷新后语言保持。
4. 商品测试核对固定规格和单位显示为越南语，名称/自定义分类保留原文，提交的 `unit`、`specification`、`productType` 不受翻译影响。模拟 API 拦截所有测试写请求，不写入业务数据库。
5. 执行 `pnpm run build:prod`；人工检查商品表单、项目中心等截图的文字与布局。

浏览器脚本为 `frontend/scripts/check-i18n-browser.mjs`。先在 frontend 启动测试预览 `pnpm exec vite --host 127.0.0.1 --port 4175`，然后在同目录运行脚本。脚本依赖已有 Playwright，可用 `PLAYWRIGHT_MODULE` 指定模块路径；默认使用本机 Edge，可通过 `I18N_BROWSER` 和 `I18N_TEST_URL` 配置。此检查验证前端显示及请求内容，不能替代真实账号、真实业务数据和服务端导出文件的联调。

本次改动仅保存在本地工作区，未提交、推送或部署。
