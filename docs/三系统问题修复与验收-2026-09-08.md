# 三系统问题修复与验收

2026-09-08，按用户确认的方案完成代码修复、数据库迁移和本地服务更新。本文对应《三系统内部检查报告-2026-09-08.md》中的已确认问题及人员写入范围问题。

## 已实现行为

| 问题 | 修复后的行为 |
| --- | --- |
| 作废成本版本导致历史金额改变 | 已计价成员工作日保留金额、币种、费率及日历依据。自动同步、查看及重算均沿用已保存结果；缺少资料的未计价日期可补计。金额纠错使用现有收支中的核算调整，不能通过作废费率覆盖旧金额。 |
| 成员改为观察员抹掉过去成本 | 保存成员角色生效记录；页面可直接调整成员角色，调整从当天生效。保留过去参与期间及已计价成本，未计价的过去参与日期仍可在资料补齐后计算。 |
| 超过计划结束日停止计费 | 仍参与的成员继续按工作日计费；实际结束日、离开日期和自定义参与结束日期继续限制计费。项目页面增加逾期提示。 |
| 延期后“跟随项目”未延长 | 资源记录独立保存参与方式，跟随项目不再受旧计划结束日期截断；自定义参与日期不被延长。迁移仅恢复能够由原立项资料确认的方式。 |
| 预算漏算负责人 | 新模板默认把负责人加入人员预算且只计一次；页面显示负责人行。负责人缺少成本时预算为待完善，不能作为完整预算启动。历史已启动预算不被批量改写。 |
| 不同币种直接相加 | 财务、老板工作台、人员汇总按币种分别展示，公司汇总及项目排名保留币种。混币时旧单值合计返回空值；没有引入汇率或猜测折算。人员及项目日结果列表显示币种。 |
| 停用/重置密码后旧登录有效 | 人员停用、密码重置、所属部门变更在提交成功后撤销该用户已有登录；请求过滤器拒绝停用或删除状态的缓存身份。 |
| 人员写入缺少范围限制 | 编辑、停用、重置密码校验目标人员的数据范围；组织变更同时校验目标部门范围。项目负责人的成员成本维护仍使用原有项目授权。 |
| 财务明细资料误显示未设置 | 补齐公司、国家、月度成本、折算工作日及成本类型；非月度计价的月度成本显示“不适用”。已有费率快照优先，无原价权限时继续隐藏费率和计算依据。 |
