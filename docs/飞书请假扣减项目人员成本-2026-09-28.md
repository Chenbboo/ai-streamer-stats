# 飞书已批准请假扣减项目人员成本

## 用户确认的口径

负责人工作台今天有人请假，人员成本仍为 965.90 元。用户确认：全天请假不计该人员当天的项目成本。该规则从 2026-09-28 起适用于 `MEMBER_DAYS_V1` 自动工作日成本。

## 实现

- 读取飞书当前修订、身份映射有效期内的已批准请假和已确认排班。连接处于当前实际使用的 `PARALLEL` 或 `ACTIVE` 状态时均可提供依据，不修改连接状态或审批流程。
- 全部排班被请假覆盖时，当日项目人员成本为零；部分请假按请假与排班的交集占比扣减。排班午休、多段班次、重叠请假和跨日区间使用已有区间运算处理。不使用多天请假总时长扣除单日成本。
- 当日应计成本 = 原项目日成本 × 剩余排班秒数 ÷ 当日排班秒数，保留两位小数。同一人员参与的项目分别扣减，不重新分配其项目投入比例。
- 保存原日成本、请假规则、生效日、来源观察记录 ID、排班秒数和请假秒数。后续刷新从原日成本重算，重复同步不重复扣减，撤销请假后恢复原日成本。
- 尚未关账项目的已生成日成本允许根据请假新修订更新；既有五分钟任务同步日明细并生成新的核算结果版本。负责人工作台和人员成本查询立即使用同一计算逻辑。
- 保留原费率、投入和日历依据。今天之前及已关账项目的已计价结果保持原快照；`ACTUAL_WORK_V1` 已确认工作和旧比例策略不在本次修改范围内。
- 有已批准请假但缺少有效排班、区间异常或质量未知时，标记待计价，金额为 null；无请假或无考勤数据不推断为缺勤。缺费率等原有待完善状态仍保留。
