# 两家公司共同管理：实施与验证

## 使用入口

老板工作台右上角 → **公司管理授权** → 选择公司 → 设置另一位老板的权限 → 填写变更原因并保存。

本机现有两家公司、两位老板已初始化四条授权。后续新增公司或老板，需要明确授权。公司授权同时受原有菜单权限约束，不授予系统管理员身份。

| 权限 | 作用 |
|---|---|
| 项目与经营管理 | 公司项目及主子项目、立项查看、KPI 设置复核、奖励核准、奖金发放登记、核算、公共费用、税率、附件和工作台待办 |
| 人员与部门 | 公司人员和组织维护、人员范围校验、离职办理；普通人事账号继续使用原数据范围 |
| 成本查看／成本修改 | 分别控制人员成本金额可见和版本维护；修改要求同时有查看权限 |
| 考勤查询 | 读取获授权公司的考勤；本人查询仍保持个人入口 |
| 飞书配置 | 单独授权连接、映射和同步维护，不因共同经营权限自动获得 |
| 验收与来源切换 | 单独授权业务验收及来源切换，初始化仅保留原公司负责人的权限 |
| 公司授权管理 | 管理另一位老板的公司授权，只能调整本人已获授的功能；无权调整的独立权限可原样保留 |

## 保留的业务边界

- 公司、部门、人员、项目、币种和月份归属独立保存。
- 原项目归属老板、主负责人、申请人不因共享管理而更换。
- 立项草稿修改和启动继续校验申请人，负责人填报及个人安排继续按本人职责处理。
- 奖励、奖金分配及计划变更继续禁止本人审核；支付防重、版本校验、行锁及关账历史快照保留。
- 每次公司授权修改记录实际操作人、原因和版本。移除公司授权后，共享管理入口和对象权限随之失效。
- 本次未修改直播、珠宝专属业务页面，也未共享个人 AI 会话、密码或任务记录。
