# P2：资源计划、实际工作与内部费率

更新：2026-09-07。本记录说明本轮已落地的代码与核算边界；总体验收结果和迁移执行记录以当前交接清单为准。

## 项目模板与计划

新立项默认 `LIGHT_V1`，可选择 `CONTROLLED_V1` 或 `SERVICE_V1`。基础项目填写目标、负责人、归属公司、计划窗口和验收要求即可启动，不以人员成本、预算、收入预测、KPI 或奖金为前置条件。受控模板提交归属老板审核，申请人与审核人必须不同；持续服务使用有限计划窗口，窗口结束日作为本周期复核节点。选择预算上限时仍检查已估算的外部支出。

模板版本、模板快照、首次基线在启动时冻结。范围、计划日期、验收要求和预算变更由独立变更单办理，保留旧基线；基础模板允许负责人授权，受控及服务模板交归属老板审核。最新预测另存，不覆盖授权基线。前端通用项目编辑和旧预算入口不能绕过新基线变更流程。

旧项目、旧立项继续使用 `LEGACY_V1` 模板及原 `PERCENTAGE_V1` 成本方法。本轮没有批量升级旧项目，未重写旧人工成本金额。旧立项服务端仍能读取有效费率完成既有测算；无独立费率权限的申请人收到的响应去掉个人费率、个人估算金额和事件原始财务快照，保留事件摘要及可办理操作。

## 资源计划与实际工作

人员参与起止日期与项目工期分开保存。资源计划支持小时、人天与容量比例；比例只用于安排资源，新实际工作填报使用小时或人天。底层统一为整数分钟，不将小数静默截断。资源安排按适用日期的容量分配分钟并处理余数，跨项目超配须说明例外原因。错误安排可停用，原记录和快照保留。

工作日历定义时区、工作周、每日容量及节假日/半天例外；单位政策单独定义一个工作人天对应多少分钟，分别新增版本并保存快照。例如六小时工作日只改变容量，不自动改变一个人天的换算定义。

实际工作使用草稿、提交、退回、撤回、确认和放弃状态。本人填报，负责人可代理填报其他成员；本人或代填人不能确认同一记录，负责人自己的工作交归属老板确认。提交时锁定人员与工作日，检查跨项目总量；超过容量必须说明，不能超过该时区自然日总分钟数。

已确认记录的更正形成新版本。新版本确认之前旧版本持续有效，确认之后旧版本被替代但保留审计，金额不会重复相加。项目交付结束但核算开放时允许补报执行期间的工作，并要求说明迟报原因；独立关账后禁止写入。草稿及待处理更正计入关账待办，可继续提交、退回、更正或放弃，不会形成无法清理的死待办。

本轮按工作日录入数量，尚未提供开始/结束时间区间的跨夜自动拆分界面。未填报显示未知或未记录，不作为零投入，也不从资源计划回填实际工作。请假与项目成果属于不同事实，飞书假勤不直接将已确认实际工作或成本归零。

关账待办统计已存在的草稿、提交、退回、撤回及更正记录；本轮没有依据资源计划自动生成逐日“应报单”或零工作声明。因此完全没有实际工作记录的基础项目不会被自动推算的人工成本阻断，概览仍保留未记录语义。

## 确认工作计价

新项目使用 `ACTUAL_WORK_V1`。工作确认事务写入耐久计价事件，后台消费者独立处理；核算失败不会撤销已确认的业务事实。全局重试按最近尝试时间轮转，单项目重试直接查询该项目，其他项目缺费率不会长期阻塞它。

费率按工作日期选取唯一有效版本，支持每月、每人天、每小时及显式币种。每日/月度费率的 `rateMinutesPerDay` 是独立的计价分母，不读取填报人选择的工作量展示单位。月度分母为标准工作天数 × 费率人天分钟数，小时分母固定为 60 分钟。

单项成本 = 已确认分钟 ÷ 费率单位分钟 × 有效单价，最终逐项采用 `HALF_UP` 保留两位小数。来源记录和修订号、工作量、工作量单位快照、费率版本及快照、币种、舍入方法、金额一并保存。缺费率、多重有效费率、币种不符或无效费率保存为待计价，金额为 null，阻断关账。原已计价快照不因后来作废费率而自动改写。

人员成本概览分开读取旧比例与新实际工作策略；新策略返回 `MISSING_ACTUAL`、`PENDING_COST` 或 `READY`。待计价和未记录金额为 null；合计只表示已计价部分，响应同时给出是否存在缺失信息，不能描述为完整的已核算成本。

## 财务内部费率菜单

独立页面为 `frontend/src/views/business/cost-policies/index.vue`，支持中文与越南语。人员管理成本入口跳转到财务内部费率，人员管理主体保留原位置。

费率列表、创建、删除与作废均要求 `business:staff:cost`。主负责人身份本身不授予原价权限；明确授予费率权限的公司负责人限定本人公司，`finance_cost_manager` 限定任职公司，明确授权的项目负责人限定所管项目成员。技术管理员可管理全域。

财务人员选择接口只返回范围内身份、公司及权限标记，不返回人员管理的电话等完整档案。新增政策只创建新版本；未来未生效且未引用的版本可删除，已生效或引用过的版本只能带原因作废。计价工作快照引用也计入引用次数。费率是内部管理核算参数，本轮不承诺工资发放或支付系统。

## 主要接口

以下工作接口前缀为 `/business/project-work`，权限除菜单权限外还由服务端检查项目归属、办理主体和状态。

| 路径 | 用途 |
| --- | --- |
| `GET /{projectId}/workspace` | 资源、工作记录、有效配置及逐行可操作标记 |
| `POST /{projectId}/assignments` | 新增独立参与区间及计划工作量 |
| `POST /assignments/{id}/retire` | 按版本停用资源安排并保留原因 |
| `POST /{projectId}/entries` | 创建草稿；带 entryId、version 更新可编辑草稿 |
| `POST /entries/{id}/submit|withdraw|discard|confirm|return` | 实际工作状态办理 |
| `POST /entries/{id}/corrections` | 对已确认工作创建更正版本 |
| `GET /entries/{id}/history` | 工作审计与更正历史 |
| `POST /calendars`、`POST /unit-policies` | 发布新配置，旧配置保持不变 |
| `POST /{projectId}/reprice` | 重试项目待计价事件 |
| `GET /{projectId}/plan` | 基线、变更及最新预测 |
| `POST /{projectId}/plan-changes`、`POST /plan-changes/{id}/review` | 变更申请与审核 |
| `POST /{projectId}/forecast` | 保存新预测 |
| `GET /business/staff/cost-options` | 财务授权范围内的最小人员列表 |
