# 公司公共费用

## 使用入口

- 财务与管理核算 → 公司公共费用：`/finance/public-expenses`。
- 负责人工作台：页面顶部“本月公共费用”，没有项目时仍可查看。
- 项目总览：项目公共费用，支持选择历史月份。
- 项目核算与收支、老板每日经营：当日公共费用及已包含公共费用的经营结果。

## 月度流程

页面按“填写费用 → 分给负责人 → 分摊进度与月结”三步展示，每次只展开当前步骤。

1. 顶部选择公司、“分摊到哪个月”和币种。第一步直接显示本月适用的费用预览；切换月份不会写入账单。
2. 点击“添加费用”，填写房租、水电等费用。年度金额覆盖从起始月开始的连续12个月；月度金额填写起止月份。金额确认用“已确定 / 先估算，月底确认”选择，备注及附件收在选填区域。
3. 点击“下一步：分给负责人”，系统生成本月账单并进入第二步。已有账单时，这个按钮先保存已修改的月度明细，再进入第二步。生成后追加的常用费用可通过“加入新增费用”补入，保留原有实际金额。
4. 老板先选择部门，再选择该部门的负责人并填写比例，也可点击“沿用上月比例”。部门列出本公司组织架构中启用的下级部门，包括尚未设置负责人的部门；换部门会清空原负责人，已有分摊和沿用上月会自动带出负责人当前所属部门。允许“暂存比例”保存不足100%的草稿；合计100%后点击“保存并下发”，确认后自动先保存比例、再下发。保存失败不会继续下发；下发失败保留已成功保存的草稿，可重试。
5. 负责人在自己的工作台将费用分配给同公司、同币种、当月有效的本人项目，可存草稿、复制上月、提交；提交时必须完整分配。提交后每日费用进入暂估成本，草稿不计入。
6. 老板在第三步查看提交进度。月份结束、所有金额已确定且承担费用的负责人已提交后，可点击“确认月结”。按钮旁显示尚缺哪些条件和最早月结日期。
7. 已结算月份保留原金额、比例、来源及操作快照。后续增减使用“登记调整”。第一步保留调整明细，顶部费用合计包含调整。

“常用费用”和“历史记录”位于页面右上角，以侧栏展示；费用停用、附件、版本及操作快照仍可访问。费用合计旁保留年度参考，项目总览支持展开每日分摊明细。

费用规则变更仅影响尚未生成的月账。已下发账单需要修改时，老板先退回并保留退回前快照，再重新下发、提交。负责人失效也可以退回重新分配。

## 金额口径

```text
公司月费用 = 当月各费用项目合计
负责人费用 = 公司月费用 × 负责人比例
项目费用 = 负责人费用 × 项目比例
项目每日费用 = 项目月费用（含该月调整）÷ 当月承担费用期间的自然日数
```

年度金额首11个月向下保留到分，尾差放入第12个月。两级分摊采用最大余数法，保证金额守恒；草稿分项合计也不会超过费用池。服务端校验比例、金额及对象权限。

每日费用向下保留到分，最后一天补齐尾差。日期范围为当月与项目期间的交集，优先使用实际起止日期，尚未确定时使用计划日期。仅截至当天的费用计入成本；未来费用保留在分摊明细中。月结将暂估改为已确认；后续调整重算已确认的原日期，保留核算版本。

月结仍生成唯一来源的 `COMPANY_PUBLIC_COST` 成本事实供追溯。按日计入的账单在经营计算中使用每日费用替代该月结事实，不重复扣费。公共费用单列为 `public_cost`，从业务成本中排除。

```text
经营结果 = 收入 − 业务成本 − 人员成本 − 奖金 − 已计入公共费用（含暂估）+ 调整
```

每日、跨日和月度报表汇总同一份日结果。月结前明确显示暂估，未下发或未提交分摊的费用提示待完善。预算已使用也包含已计入的公共费用。V100启用前已经月结的历史账单保留原记录及原月结口径。

例：项目承担4,800元，费用期间为30个自然日，每天计入160元；截至第15天累计2,400元。月结确认4,800元，不再额外扣除一次4,800元。

公共费用进入全成本预算与按利润计算的管理费基数。不能再手工录入相同公共费用，不能单独冲销系统分摊流水。

## 项目结束、交接与纠错

- 关账检查覆盖相关月份公共费用，包括有效规则尚未生成月账的情况。
- 月中交付结束但费用仍待月结时，老板可选择“结束交付，待月结”，保存实际结束日期，核算保持开放；次月费用月结后，再关闭核算、结算管理费。
- 验收型项目需确认当前待验收记录；旧版项目需明确确认将本项目的交付结束与核算关闭分开，其他历史成本、预算及政策保持原值。
- 项目交接前，原负责人须提交已下发费用的项目分摊。已提交分配保留原负责人快照，交接不会废除历史费用。
- 已月结但项目核算仍开放：在原费用月账登记正负差额；负调整不得使项目当月公共费用小于0。
- 项目已关账：使用项目“交付与结算 → 关账后调整”，按审核当期记录经营结果差额，保留原账及管理费结算依据。

## 权限与并发

启用的老板角色可切换管理两家公司的独立费用账单，公司组织负责人也可管理本公司账单；仅有技术管理员身份不会自动获得此项业务管理权限。新分配候选人排除离职、停用账号及停用部门人员，历史分摊快照保留。负责人只能修改本人承担费用并分给符合条件的本人项目。项目查询遵循对象权限，不直接混加不同币种。

规则及月账携带版本号；写入使用事务、行锁和唯一来源键。调整请求使用稳定请求标识，防止重试重复记账。

## 数据库与启用

备份数据库后执行 `backend/sql/migrations/V097__company_public_expenses.sql`，再启用配套后端及前端。迁移新增7张表、日结果公共费用列、专用成本类别及财务菜单，保留原经营数据。

`verify_business_schema.sql` 包含新菜单路径检查。迁移可重复执行。回退须保留新账单、分配、调整及审计记录。
