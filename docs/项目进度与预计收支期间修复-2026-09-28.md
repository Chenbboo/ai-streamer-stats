# 项目进度与预计收支期间修复（2026-09-28）

本次仅修复《项目数据期间口径检查-2026-09-28》中的月度进度跨期间比较、有限期项目一次性预计收支漏算。预算周期标题、KPI 默认方案和公共费用分摊提示仍属于独立待办，不在本次修改范围内。

## 进度展示

- 后端继续选择当前自然月最后一份进度汇报，不改变 SQL 月度重置规则。
- 页面依据 `progressReportId` 区分缺报与真实的 0% 汇报。缺报显示“本月尚未汇报”，不再从任务完成数推导月度完成率。
- 项目总览和进度弹窗使用同一展示规则；已关闭 100%、已取消 0% 的终态规则保留。仅有历史接收权限的档案不冒充当前月进度。
- 全项目计划时间比例单独展示，不再与月度完成率相减或据此触发落后警告。新增文案含越南语翻译。

## 预计收支

- 有明确结束日期的全项目重新测算计入全部一次性预计收入（BASE 情景）和计划支出，包括通过既有前后六个月日期校验的筹备支出、尾款。日期校验不放宽。
- 月度预测覆盖获准一次性收支的实际发生月份；没有日期的一次性项目、主项目拨款只计入项目开始月。
- 人员成本和周期性收支仍只覆盖执行期间，执行期外的现金月份人员成本为零，不查询该月人员费率；月度舍入调整只作用于执行月份。
- 周/月/季度/年度不限期预算继续按该预算的精确日期筛选，不变成无限累计。
- 新测算月表标识为 `CALENDAR_MONTH_V3`。已有 `CALENDAR_MONTH_V2`、V3 有限期快照读取时不重算；无版本旧快照的派生月表仍沿用执行期收支规则，保存总额、费率依据和历史审批快照不变。
- 有限期月表预览最多 72 个月，覆盖原五年执行预览及两端各六个月的现金窗口；更长项目仍为截断预览，不承诺月表等于全期总额。
