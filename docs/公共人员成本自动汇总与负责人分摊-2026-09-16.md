# 公共人员成本自动汇总与负责人分摊

## 操作方式

公司公共费用 → 公共人员成本 → 下一步：设置分摊对象和比例。

系统从人员成本设置读取当月有效成本，扣除项目直接承担金额，汇总待分摊成本。老板选择部门、负责人及承担比例；公共人员成本和日常公共费用分别设置比例，统一下发。负责人仍在自己的工作台分配到项目。

人员金额和来源明细只读，取消手动修改月总成本、关联人员支出、填写核实依据的表单。缺少月份覆盖、项目投入或确认信息时，显示原因并阻止保存，不将未知金额当作零。

## 保存及历史记录

- 新保存接口只接收公司、月份、币种及月账版本，后台重新计算金额；拒绝旧客户端提交人员金额行。
- 新快照标记为 AUTOMATIC，月结重新检查成本来源及金额；历史人工核实快照保留原校验方式。
- 已保存的历史支出关联由后台继续核对并扣除，不增加新的人工关联入口，避免更新时重复分摊。
- 已下发月账需退回后更新，已结算月账保持只读。本次没有修改实际人员费率、分摊比例或已下发账单。

## 2026-09-29：项目删除后的投入比例自动转分

- 已取消项目沿用实际结束日的现有规则；补齐已删除项目的历史比例来源。查询保留已删除项目的有效比例版本，以删除事件日期确定最后参与日，旧数据缺少事件时使用项目更新时间；已有更早结束日时不延长参与期间。
- 最后参与日后的次日，将释放的已确认比例平均加到其余有效项目。采用现有两位小数精度，按项目 ID 稳定处理尾差，总比例不超过 100%；新的人工分配优先，待确认比例不会自动获准。无剩余有效项目时不生成新项目投入。
- 公共人员成本预览、成员跨项目比例和自动人员日成本共用同一份时间线。历史预览保留删除项目名称及币种依据，不改写已保存账单、审批记录或已计价成本。
- 截图核对：石头月成本 9,375.00 元，3 个项目各 25% 时直接承担 7,031.25 元，剩余 2,343.75 元。若第 4 个项目的 25% 已释放，其余比例为 33.34%、33.33%、33.33%，项目金额合计 9,375.00 元，公共剩余为 0。金额仍按现有累计舍入规则守恒。
