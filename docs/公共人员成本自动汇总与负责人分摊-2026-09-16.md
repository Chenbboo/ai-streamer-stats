# 公共人员成本自动汇总与负责人分摊

## 操作方式

公司公共费用 → 公共人员成本 → 下一步：设置分摊对象和比例。

系统从人员成本设置读取当月有效成本，扣除项目直接承担金额，汇总待分摊成本。老板选择部门、负责人及承担比例；公共人员成本和日常公共费用分别设置比例，统一下发。负责人仍在自己的工作台分配到项目。

人员金额和来源明细只读，取消手动修改月总成本、关联人员支出、填写核实依据的表单。缺少月份覆盖、项目投入或确认信息时，显示原因并阻止保存，不将未知金额当作零。

## 保存及历史记录

- 新保存接口只接收公司、月份、币种及月账版本，后台重新计算金额；拒绝旧客户端提交人员金额行。
- 新快照标记为 AUTOMATIC，月结重新检查成本来源及金额；历史人工核实快照保留原校验方式。
- 已保存的历史支出关联由后台继续核对并扣除，不增加新的人工关联入口，避免更新时重复分摊。
- 已下发月账需退回后更新，已结算月账保持只读。本次没有修改实际人员费率、分摊比例或已下发账单。
