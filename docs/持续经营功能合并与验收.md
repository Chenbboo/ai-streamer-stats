## 功能与兼容规则

| 范围 | 当前行为 |
| --- | --- |
| 不限期与预算 | 保留不限期、周/月/季度预算、人员完整工作日与有效费率估算。新增总额上限、每日上限、不设上限；总额上限仍由人员预算加业务预算计算。每日控制可选全成本或仅外部支出，不与累计成本比较。不设上限须说明原因，仍保留计划测算。 |
| 启动预算与重复收支 | 收支支持一次性/每日/每周/每月；每天按实际期间天数、每周按天数÷7、每月按天数÷30折算，明示为计划测算。每日模式的启动支出需另设启动预算，总额模式下启动预算包含在总额内。实际业务日的成本预警仍按当日已入账成本统计。 |
| 首月与稳定月 | 首月从项目开始日至该自然月末；稳定月为下一个完整自然月，排除一次性收支。人员费用按该月日历、参与时间及有效费率计算；缺费率保持未知。 |
| 计划变更 | 新项目预算控制、期间与收支假设写入版本快照；变更/续编重新估算有效人员安排，并保留收支假设。延续当前负责人授权/独立复核规则。 |
| 每日目标 | 项目可按总目标或持续经营跟踪；持续工作支持固定每日、总量自动分配、负责人每日下达、无量化四种模式。修改每日目标必须说明原因，保留旧版本；员工提交后禁止修改。项目与持续工作加锁核对，防止并发填报和修改绕过冻结。 |
| 启停与历史 | 任务与持续工作支持停用、恢复；每段启用区间、执行人快照保留。过期自动分配工作恢复时需新的结束日期。自动创建的项目交付任务同样保存首段区间。动态显示操作人与被安排人姓名/账号。 |
| 工作台 | 员工按项目筛选任务、持续工作与旧比例投入；实际工作入口携带当前项目。项目奖金分别汇总已确认历史联动奖金和已核准独立奖励，不重复计入独立 KPI 结果；不同币种分列，不表示个人分配或工资实发。 |
| 权限 | 个人菜单只能在目标员工角色上限内收敛；人员目录在 SQL 层统一处理范围、过滤和分页，继续保留当前独立费率权限。 |
| 附件 | 多文件上传结束后合并并去重，成功、失败与卸载均释放加载状态；授权下载尽量保留原始文件名。 |

当前立项自主启动、交付/核算分离、实际工时计价、独立奖励及飞书假勤规则继续有效。旧五领域设计仅在 [历史快照](./archive/标准产品-二次领域拆分设计-20260907.md) 中保留，不替代三系统产品设计。
